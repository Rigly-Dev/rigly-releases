# Rigly

**Rigly is a local PHP development environment for macOS**, now in public beta. It serves your projects at
`name.test` with Caddy, every PHP version from 7.4 to 8.5, Node, databases, a mail catcher, dumps and public
sharing, from a native menu bar app.

- **Download:** [Rigly.dmg](https://github.com/Rigly-Dev/rigly-releases/releases/latest/download/Rigly.dmg)
  (macOS 15 or later). Rigly updates itself after that.
- **Website and documentation:** [getrigly.com](https://getrigly.com)
- **Release notes:** [Releases](https://github.com/Rigly-Dev/rigly-releases/releases)

## Feedback

Rigly is in beta, and your feedback shapes it. Found a bug, missing something, or have a question?
[Open an issue](https://github.com/Rigly-Dev/rigly-releases/issues/new/choose), or choose **Send Feedback…**
in Rigly's menu, which fills in your Rigly and macOS versions.

This repository holds Rigly's downloads, its update feed and its issue tracker. Rigly's source code isn't public.
